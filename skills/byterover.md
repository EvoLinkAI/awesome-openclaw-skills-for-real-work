## What It Does

ByteRover is a financial data tool that gives your agent access to real-time and historical market data: stock prices, crypto prices, financial statements, market news, and more. Perfect for investors, traders, and anyone who needs up-to-date financial data.

## How to Install

```bash
clawhub install byterover
```

**Optional setup for higher limits:**
1. Get an API key from [byterover.ai](https://byterover.ai/)
2. Set env var: `export BYTEROVER_API_KEY="your-key"`

## Key Capabilities

- Real-time stock prices and quotes
- Historical price data for stocks, ETFs, and crypto
- Financial statements: income statement, balance sheet, cash flow
- Market news and earnings announcements
- Crypto prices and market data
- Portfolio tracking and performance analysis
- Free tier available for personal use

- Free tier has rate limits — upgrade to paid for heavy usage
- Data is delayed by 15-20 minutes for most exchanges; real-time data available in paid tier
- Always verify financial data with a second source before making investment decisions
