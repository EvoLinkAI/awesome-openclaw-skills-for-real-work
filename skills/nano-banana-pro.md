## What It Does

Nano Banana Pro is a highly opinionated collection of terminal shortcuts and utilities designed to make common command-line tasks faster. It's a "Swiss Army knife" with pre-configured aliases and scripts for common operations. Extremely niche for power users who prefer minimal, opinionated tools.

- Pre-configured aliases for common CLI tasks
- Minimalist design, no bloat
- Fast execution, no dependencies
- Curated set of utilities for file operations, text processing, and system administration
- Cross-platform support

## Usage Examples

**Common shortcuts:**
```
nbp find-large-files      # Find files larger than 100MB
nbp clean-tmp             # Clean temporary files
nbp network-stats         # Show network usage statistics
nbp disk-usage            # Human-readable disk usage
```
